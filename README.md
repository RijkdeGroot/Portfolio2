# Rijk de Groot Portfolio

Static portfolio website for showcasing projects, about information, and contact details.

## Files
- `index.html` – landing page
- `projects.html` – portfolio gallery
- `about.html` – personal background and tools
- `contact.html` – contact form
- `css/` – stylesheets
- `js/` – site behavior and project data
- `images/` – project images and media

## Upload to GitHub
1. Initialize the repository locally:
   ```bash
   git init
   git branch -M main
   git remote add origin https://github.com/YOUR_USERNAME/YOUR_REPO.git
   ```
2. Commit and push:
   ```bash
   git add .
   git commit -m "Initial portfolio upload"
   git push -u origin main
   ```

## GitHub Pages
This project is static and can be published through GitHub Pages directly from the main branch.
